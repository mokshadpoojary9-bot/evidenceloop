# Demo evidence: sources and licence

Every file in this folder was made for EvidenceLoop by the project itself. Nothing was downloaded,
photographed, traced or generated by an AI image model. Rooms, products, brands and model numbers
(**Lumora EL-2040**, **Brackwell BX-6**, **Aerivo CF-48 / CF-52**) and the SOP codes are fictional.

**Free to use.** You may copy, modify and redistribute these files for any purpose, without
attribution (public-domain dedication, CC0 1.0).

To rebuild them all: `node demo/src/make-demo-files.mjs` (needs Microsoft Edge; ffmpeg and pdfkit
come from the project's dependencies).

field-service app stamps on a photo.

## How the seed uses them

`npm run seed:demo` uploads these files through the same code as the API and runs the **DEV ONLY
fixture**, which never opens a file. It only checks which kinds of evidence are attached, so every
seeded result is labelled *Simulated · dev fixture*. The fixture cannot see that the Lab 3 label
reads CF-48, so that upload's note carries the fixture's `#contradict` tag. Real verification of
these files happens only when you run Nemotron on them (see `DEMO.md`).

These are drawn illustrations, not photographs. A real model may judge them more cautiously than a
real site photo, and EvidenceLoop will say so rather than guess.

`src/take-screenshots.mjs` takes the README screenshots in `docs/screenshots/` from the seeded data.
